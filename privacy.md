# Athena - Privacy Policy

Last updated: 8 November 2026

Athena is a private assistant used only by its owner, Francesco Gallista. It is not offered to the public.

## What data Athena accesses

With the owner's explicit consent, Athena reads and organizes email from the owner's own Google accounts through the Gmail API.

## How the data is used and stored

- Data is processed only on the owner's personal computer and home storage.
- Data is never sold, shared with or transferred to third parties.
- Data is not used to train artificial intelligence or machine learning models.
- Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
